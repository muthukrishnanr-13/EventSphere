&#x20;EventSphere - Event Feedback Management System



&#x20;📌 Project Overview



EventSphere is a web-based Event Feedback Management System designed to collect, store, and display feedback from users who participate in different events.



The system provides a simple and user-friendly interface where users can select an event, submit their name, email, and feedback message. The submitted feedback is securely stored in MongoDB Atlas through a Node.js and Express.js backend.



&#x20;✨ Features



\- 🏠 User-friendly homepage

\- 🎯 Multiple event pages

\- 📝 Online feedback submission

\- 📊 Display of recent feedback

\- ☁️ Cloud-based MongoDB database

\- 🚀 Deployed backend using Render

\- 🌐 Deployed frontend using GitHub Pages

\- 📱 Responsive web interface

\- 🔗 Frontend and backend API integration
