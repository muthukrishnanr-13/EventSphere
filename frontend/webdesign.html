Web Design Challenge

Design and build attractive, responsive, and user-friendly websites by combining creativity, modern design principles, and web development skills.

← Back to Events

About the Event

The Web Design Challenge gives participants an opportunity to create a modern website based on a given theme or problem statement. Participants will focus on visual design, usability, responsiveness, and functionality.

Objective

The objective is to encourage participants to develop creative web solutions while demonstrating their knowledge of HTML, CSS, JavaScript, responsive design, and user experience principles.

Event Information

👥 Participants Individual or Team
⏱ Duration 2–3 Hours
📍 Mode On-site
🎯 Level Beginner to Advanced

Challenge Format

  • A website theme or problem statement will be provided.
  • Participants plan the website structure and layout.
  • Create responsive web pages.
  • Implement the required features.
  • Present the completed website to the judges.

Technologies

  • HTML5
  • CSS3
  • JavaScript
  • Bootstrap
  • Responsive Web Design
  • Git and GitHub

Judging Criteria

  • Creativity and originality
  • Visual design and layout
  • User experience
  • Responsiveness
  • Functionality
  • Code quality
  • Presentation

Rules & Guidelines

  • Participants must follow the given theme.
  • Designs should be original.
  • Website must be responsive.
  • All work must be completed within the given time.
  • Participants must present their final website.

What You Will Learn

  • Modern website design principles
  • Responsive web development
  • UI and UX fundamentals
  • Frontend development techniques
  • Creative problem solving
  • Website presentation skills

Prizes & Recognition

The best designs will receive prizes, certificates, recognition, and an opportunity to showcase their creative work.
